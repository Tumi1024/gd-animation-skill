# L004: Derive Math Constructs From The Given Problem Objects

## Original Request

Create a demo animation from a script about an exhibition hall activity. The relevant math parts were:

- A creative puzzle area where Pipi and Danjun must first determine the axis of symmetry, then add puzzle pieces to complete an axially symmetric figure.
- A route-planning activity where viewers must go from the entrance to the display wall and then to the exit, with a hidden shortest-route reward.

## Initial Plan Problem

The animation initially treated the axis of symmetry as a generic canvas centerline, then as a line derived from abstract corresponding points. Both versions missed the actual given objects in the problem:

- The left side already had three shapes.
- The right side already had the corresponding triangle.
- The axis should be determined from the two triangles' corresponding vertices, not from arbitrary helper points or the board center.

The route segment also showed a direct entrance-to-exit curve, which weakened the stated requirement that the route must pass through the display wall.

## User Feedback

The user clarified:

- The first part should show the left three shapes and the right triangle.
- Use two pairs of corresponding triangle vertices to determine the axis of symmetry.
- Then place only the two remaining right-side shapes according to that axis.
- The second part must clearly show a route from entrance to display wall to exit.
- Do not show a direct entrance-to-exit curve because it makes the wall requirement ambiguous.

## Final Revision Direction

For the puzzle:

1. Show the exact known givens first: left triangle, left curved block, left circle, and the known right triangle.
2. Highlight two pairs of corresponding vertices on the two triangles.
3. Draw the two connecting segments.
4. Mark their midpoints.
5. Draw the common perpendicular bisector and label it as the axis of symmetry.
6. Keep that axis as the construction reference.
7. Add only the missing right curved block and right circle.

For the route:

1. State and visualize the constraint first: entrance -> display wall -> exit.
2. Show a candidate wall-touching route, not a direct entrance-to-exit curve.
3. Use reflection only after the wall-touching constraint is visually established.
4. Highlight the shortest wall-touching route as entrance -> touch point -> exit.

## Reusable Lesson

In math demo animations, every construction must be derived from the exact objects and constraints given in the problem. Do not replace problem objects with abstract guide points, decorative centerlines, or simplified routes unless the script explicitly abstracts them first.

When explaining how to determine an axis of symmetry from a partially completed figure, the animation should use known corresponding points from the existing figure. If a known corresponding pair is a triangle, use the triangle's corresponding vertices, connect them, find the midpoint, and draw the perpendicular bisector.

When explaining a shortest route with a required intermediate object, show the route constraint before the optimization. If the path must touch a wall, the preview should never show a direct entrance-to-exit route as the baseline.

## Error Type

- Knowledge expression error
- Animation design error
- Spatial relationship error
- Constraint omission

## Checklist For Future Tasks

- Identify the exact known objects in the problem before drawing helper geometry.
- Ask: "Which existing object proves this construction?" before animating an axis, route, center, tangent, midpoint, or mirror line.
- If the script says "first determine X", animate the determination process before using X.
- Do not use abstract points when the problem provides concrete points, vertices, blocks, landmarks, or route nodes.
- For route optimization, draw the required route form before drawing the optimized route.
- If a route must pass through a wall or checkpoint, never show a direct start-to-end path as the main comparison.

# L003 Verify Alpha Channel In Transparent Exports

## Tags

transparent-export, technical-implementation-error, export-format-error

## Error Type

technical-implementation-error / export-format-error

## Error Manifestation

A transparent .mov export was requested, but an initial ProRes file used a non-alpha pixel format. The file extension and codec were not enough to guarantee transparency.

## Correct Approach

Export with an alpha-capable codec and image pipeline, then verify with media metadata. For ProRes, confirm a yuva pixel format such as yuva444p12le. In Remotion, PNG image frames and an alpha pixel format may be required.

## Reusable Rule

For transparent video delivery, always verify the exported file's pixel format contains alpha; do not rely only on .mov or ProRes labels.

## Applicable Scenarios

Transparent overlays, compositing assets for editing software, alpha-channel explainers, lower thirds, animated labels, and insertable course animation elements.

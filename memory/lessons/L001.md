# L001 Stage Knowledge Points Instead Of Stacking Visuals

## Tags

science, structure-breakdown, animation-design-error, visual-layout-error

## Error Type

animation-design-error / visual-layout-error

## Error Manifestation

A molecular structure animation showed the molecule, bond angle, polarity arrow, labels, and explanatory text in the same frame. The result was visually crowded and the viewer could not tell which knowledge point to focus on.

## Correct Approach

Separate the explanation into stages: first structure, then angle, then spatial rotation, then polarity. Keep only the current stage's necessary helper elements visible.

## Reusable Rule

When a subject has multiple knowledge layers, reveal one layer per stage and remove or fade helper elements before introducing the next layer.

## Applicable Scenarios

Science structure animations, molecular models, mechanical breakdowns, anatomy diagrams, astronomy systems, and any explainer with several simultaneous visual annotations.
